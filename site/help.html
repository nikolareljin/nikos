Where to get help

The Help entry in the applications menu opens this page. NikOS documents itself here; the desktop underneath it is Xubuntu, and Xubuntu documents that.

NikOS itself

NikOS is an Ansible playbook and the desktop configuration it applies. Anything specific to it lives on this site, at nikolareljin.github.io/nikos:

  • Installing and updating — choosing a version, re-running the playbook, and what to do when a run fails partway.
  • What's included — every role, the packages it installs and the commands it provides.
  • About — what the project is for, and the other projects it pulls in.
  • Issue tracker — anything that looks like a bug in the playbook or the desktop configuration.
  • Source — the playbook itself, which is the authoritative answer to "what does this actually do".

The desktop, which is Xubuntu

NikOS does not replace the desktop. It installs Xubuntu and configures it, so what you are using is Xfce as Xubuntu ships it, with a Nord theme and a different panel menu on top. Thunar, the panel, the settings manager, workspaces, keyboard shortcuts, printing and removable media are all Xubuntu, and Xubuntu documents them properly:

  • Xubuntu documentation — the full user guide for the desktop, its applications and its settings.
  • Xubuntu help and support — mailing lists, IRC and the community forums.
  • xubuntu.org — the project, its news and its release notes.
  • Xfce documentation — the upstream desktop environment, for anything below the Xubuntu layer.
Why this page and not the offline handbook? NikOS installs xubuntu-desktop-minimal rather than the full xubuntu-desktop, so the offline documentation package is not pulled in. It is about 78 MB installed and is still at version 22.04, while the site above tracks the current release. Install it if you want the handbook available without a network: 
sudo apt install xubuntu-docs
