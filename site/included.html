What NikOS installs

Twelve roles run on every install. Fifteen more are opt-in, and nothing in them is downloaded unless you ask. Every item below maps to a role you can read in the repository.

The Python AI environment

A conda environment named nikos-ai, built on Miniforge. Python is a range (>=3.11,<3.14) rather than a fixed minor, so conda resolves whatever actually solves against the package set.

OpenCV's wheels are dynamically linked, so libgl1, libglib2.0-0t64, libsm6, libxext6 and ffmpeg are installed alongside them. Tesseract arrives with orientation detection and nine language packs by default; set nikos_tesseract_languages: ["all"] for all 160-plus.

Tesseract reads text, it does not translate it. It performs OCR — extracting characters from an image. Translating what it extracts is a separate step, and one of the local language models can do it.

Ollama models

Models come in modules, and each module pulls one model per role: the one this machine can run. The model per role and class of machine is the fleet's approved set, in ai-models.env. The default module is always pulled; the others with nikos add ollama-text, -reasoning, -coding, -vision, -embedding, or ollama-models for every role.

The class is measured: small has less than 11 GiB of memory and of GPU memory; large has a GPU with 11 GiB or 30 GiB of memory; xlarge has a GPU with 15 GiB (reasoning) or 23 GiB (code); standard is the rest. Disk and memory are checked before each pull, and a model that does not fit falls back one class. nikos_ai_model_tier names the class instead; nikos models shows it.

nikos update pulls the default and the selected modules, and first offers to remove installed models that are not approved for this machine, one question per model. Without a terminal it lists them and removes nothing. nikos add model <name> installs any other model, and updates keep it.

The nikos command

nikos setup            # run the full playbook
nikos update           # move to the newest release, then re-run
nikos update --ref X   # update to a specific branch or tag
nikos add <name>       # install an optional bundle or model group
nikos status           # version, Ollama models, installed roles
nikos doctor           # check for broken configs and missing deps
nikos clean [--apply]  # free disk from unused caches; never volumes
nikos log [N]          # tail the latest playbook log
nikos log list         # list available logs
