About

Nik Reljin

NikOS is one project out of a set that mostly points the same direction: software that runs on your own machine, does one job well, and can be read start to finish.

What I work on

Five threads run through most of it.

Local-first AI

Inference that runs on hardware you own, without a request leaving the machine. Model compression and finetuning so smaller hardware stays viable.

Developer infrastructure

Reusable CI, shared shell libraries and repo tooling — the parts that get copy-pasted between projects until someone factors them out.

Security tooling

Finding credentials before they ship, and removing them from history once they have. Scanners that produce evidence rather than adjectives.

Hardware that does something

E-paper companions, Android display nodes, second lives for a Raspberry Pi or an old Kinect. Small devices with a clear job.

Terminal-first interfaces

TUIs and CLIs for work that does not need a browser: markdown reading, image preview, repository dashboards.

Security

Leak Lock

A VS Code extension that finds secrets in git history, verifies whether the credentials are still live, and rewrites them out of every branch and tag — with a script you can read before running it.

Repository Site

claude-reposec

Deep-scans a repository for secrets, PII, code vulnerabilities, history leaks and dependency CVEs. Secrets are redacted in all output; --ci fails the build on high findings.

Repository Site

credential-lens

Safely inspects SSH key files and compact JWTs, producing evidence-based facts for security-review tooling rather than guesses.
